# Data Science & AI Engineering Portfolio

Welcome to my professional portfolio! This repository showcases my projects, practical implementations, and continuous learning journey in the fields of **Data Science**, **Machine Learning**, **Data Analysis**, and **AI Engineering**.

## 🚀 Featured Projects

* **Warsaw Real Estate Price Estimator:** A machine learning model (built with PyCaret) integrated into a Streamlit web application to predict property prices in Warsaw, featuring custom UI styling and Langfuse tracing.
* **AI Video Subtitle Generator:** An automated tool designed to process video files, extract audio, and generate accurate subtitles seamlessly.
* **Multimedia Chatbot Assistant (RAG):** An interactive chatbot assistant leveraging Retrieval-Augmented Generation (RAG) and OpenAI APIs to answer queries based on custom document contexts.
* **World GDP Dashboard:** An interactive data visualization dashboard exploring global GDP metrics, economic trends, and country-level comparisons.
* **Olist E-Commerce EDA:** Exploratory data analysis of Brazilian e-commerce data using Python (Pandas, Seaborn) and SQL to extract actionable business insights.
* **Iris Dataset Domain Exploration:** An in-depth EDA and domain-driven analysis of the classic Iris dataset.
* **Airbnb Market Analysis:** Data exploration and visualization dashboard focusing on rental market trends.
* **Additional Utilities & Apps:** Interactive web applications leveraging environment secret management and automated tools (such as a language helper).

## 🛠️ Tech Stack & Tools

* **Languages & Core Libraries:** Python, Pandas, NumPy, Scikit-Learn, PyCaret
* **Data Visualization & Web Apps:** Matplotlib, Seaborn, Streamlit
* **AI & LLM Integration:** OpenAI API, RAG (Retrieval-Augmented Generation), Langfuse tracing
